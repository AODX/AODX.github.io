# ECLIPSE DUEL — V23 RETAIL STABILIZED

이 프로젝트는 v19 원본에 v20~v22 기능을 정리하고, v23에서 데스크톱 UI 레이아웃/카드 렌더링/네트워크 복구/전투 동기화 안전장치를 다시 통합한 전체 교체본입니다.

## 가장 안전한 적용 방법
1. 현재 프로젝트를 백업합니다.
2. `.env.local` 또는 Render/Supabase 환경변수는 별도로 보관합니다.
3. 이 ZIP의 프로젝트 파일로 기존 코드 전체를 교체합니다.
4. 기존 Supabase DB를 그대로 사용할 경우 추가 SQL 실행은 필요하지 않습니다.
5. 새 Supabase 프로젝트에서 처음 설치하는 경우 `sql/00_ALL_IN_ONE_FRESH_INSTALL.sql`을 사용합니다.

## 이번 버전의 핵심 원인 수정
이전 화면 깨짐의 가장 큰 원인 중 하나는 카드 내부 `i` 상세보기 요소가 카드 CSS Grid의 한 칸으로 계산되어 카드 아트 영역을 밀어내던 것입니다. v23에서는 카드 구조 자체를 수정하여 상세보기 버튼을 절대 위치 오버레이로 분리했고, 카드 아트/텍스트/푸터의 행을 고정했습니다.

또한 이전 패치는 누적 CSS 상태에 따라 결과가 달라질 수 있었습니다. v23 전체 교체본에는 `globals.css`, `theme-v19.css`, 새 `theme-v23.css`가 일관된 세트로 포함되어 있습니다.
