# ECLIPSE DUEL v26 — Expansion & Cosmetics

## 1. 카드 풀 확장
기존 320장에서 200장을 추가하여 총 520종으로 확장했습니다.

신규 시리즈는 각각 정확히 40장입니다.
- 시간성전 크로노리움 — 시간 가속 / 에너지 재배치
- 마도규약 아르카나 프로토콜 — 주문 연쇄 / 서치
- 야수기갑 비스트포지 — 야수 강화 / 보호막
- 몽환극단 팬텀 카니발 — 함정 연계 / 묘지 회수
- 성해함대 아스트라 아르마다 — 편대 전개 / 실드·에너지

각 시리즈 구성:
- 유닛 22
- 주문 8
- 함정 6
- 융합 2
- 진화 2
- 전설 6장 포함

기존 SERIES LINK 엔진을 그대로 사용하므로 단순 수집 카드가 아니라 서치·회수·강화·보호막·에너지·코어 압박 연계가 실제 전투에서 작동합니다.

## 2. 프로필 문양
프로필 아이콘(아바타)과 별개로 구매 가능한 '문양' 슬롯을 추가했습니다.

신규 문양:
- 태양의 문장
- 월영의 눈
- 카이저 크라운
- 균열 오메가
- 아스트랄 윙

장착 문양은 프로필 카드뿐 아니라 상단 프로필 칩과 대전 리더 HUD에도 노출됩니다.

## 3. 카드 슬리브 / 카드 뒷면
카드 보호 필름처럼 보이는 별도 슬리브 슬롯을 추가했습니다.

신규 슬리브:
- 이클립스 블랙
- 솔라 플레어
- 루나 글라스
- 카이저 크롬
- 보이드 프리즘
- 아스트랄 네이비

장착 슬리브 적용 영역:
- 상대 손패 뒷면
- 상대의 비공개 함정 카드
- 3D 드로우 연출의 덱/카드 뒷면
- 팩 개봉 전 뒤집힌 카드
- 프로필 편집 미리보기

상대의 실제 카드 정보는 공개하지 않고 공개 프로필의 슬리브 ID만 사용합니다.

## 4. 카드 아트 고유화
기존 카드 중 서로 지나치게 비슷하게 보이던 아트를 전수 검사하여 의심군을 교체했고 신규 200장에는 각 ID 전용 아트를 생성·매핑했습니다.

최종 검사:
- 카드 520종
- 아트 520개
- 누락 0
- 손상 0
- SHA-256 정확 중복 0
- 강한 저해상도 시각 유사도(0.940 이상) 0쌍

`scripts/verify_art_uniqueness.py`를 제공하여 이후 새 카드를 추가할 때도 같은 검사를 반복할 수 있습니다.

## 5. 상점 / DB
기존 프로필 꾸미기 RPC를 v26으로 확장하여 배경·프레임·문양·슬리브를 하나의 보유 테이블로 관리합니다.

기존 v25 DB에서 업데이트:
`sql/06_V26_EXPANSION_COSMETICS.sql`

새 설치:
`sql/00_ALL_IN_ONE_FRESH_INSTALL.sql`

신규 200장은 카드 카탈로그에 등록되며 기존 3개 코어 팩과 13개 시리즈 팩에서 정상적으로 획득할 수 있습니다.

## 6. 유지된 기존 기능
- 스타터 덱 전설 1장
- 현재 소환 가능한 전설 표시
- 3D 드로우
- 시리즈팩 / SERIES LINK
- 글로벌 채팅 30분 보존 및 정리
- 대전 재접속 / 상태 동기화

## 7. 애니메이션 프로필 꾸미기 / 닉네임 FX
정적인 색상 교체가 아니라 실제 시간 기반 애니메이션이 적용되는 프로필 꾸미기를 추가했습니다.

### 신규 애니메이션 배경
- 성운 와류 — 성운과 궤도광이 회전
- 크로노 균열 — 시계/시간 균열 문양이 드리프트
- 기존 전설 `공허의 왕좌`에도 미세 성운 이동 효과 추가

### 신규 애니메이션 프레임
- 프리즘 루프 — 무지개 광선이 프레임 둘레를 순환
- 홍염의 관 — 불꽃 입자가 테두리에서 상승
- 기존 전설 `성계의 관`에도 궤도 회전 효과 추가

### 닉네임 꾸미기 상점
구매 및 장착 가능한 닉네임 FX 7종을 추가했습니다.
- 레인보우 시프트
- 네온 펄스
- 스타라이트
- 홍염 파동
- 보이드 글리치
- 오로라 웨이브
- 황제의 서명

닉네임 FX는 로컬 장식이 아니라 `nickname_style`을 DB에 저장합니다. 장착한 스타일은 다음 영역에서 다른 플레이어에게도 동일하게 표시됩니다.
- 프로필 / 상단 프로필 칩
- 친구 목록 및 친구 요청
- 글로벌 채팅 / 결투방 채팅
- 대전 리더 HUD
- 결투방 로비
- 선공 결정 연출
- 대전 행동 피드의 상대 이름

글로벌/방 채팅은 메시지 생성 시 당시 닉네임 스타일 ID도 함께 저장하여 모든 접속자에게 같은 효과를 렌더링합니다.

애니메이션은 `prefers-reduced-motion` 환경에서는 자동 정지되어 접근성 설정을 존중합니다.
