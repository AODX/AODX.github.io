# ECLIPSE DUEL V23 — Retail Stabilization

## 1. UI 붕괴 원인과 수정
- 카드 상세보기 `i` 요소가 카드 Grid 레이아웃에 참여하면서 아트 영역을 밀어내던 구조 수정
- 표시 카드의 루트 요소를 접근 가능한 card control 구조로 정리하고 상세보기 버튼을 독립 오버레이로 변경
- 카드 아트 이미지의 position/z-index/object-fit/visibility를 v23 최종 레이어에서 강제 고정
- 카드 상세 모달을 고정 높이 2단 구조로 재설계하여 아트 영역 collapse 방지
- 상단 SYSTEM 컨트롤 크기/간격을 강제 정상화
- 설정창은 데스크톱 우측 패널로 고정하고 ESC/backdrop/focus 복구 지원
- 덱 빌더, Deck Doctor, 현재 덱 리스트, 엑스트라 덱 레이아웃 재정렬
- 수집률/희귀도 현황을 카드 보관함의 정식 HUD로 정리
- 카드팩은 반복된 대형 원본 아트 대신 실제 카드 3장 + 별도 booster package 프리뷰 구조 사용
- 프로필 스킨은 구매 전에 실제 프로필 카드에 적용된 형태로 미리보기
- 장착한 프로필 배경/프레임이 실제 프로필 카드에도 반영되도록 수정

## 2. 서비스/네트워크 안정성
- bootstrap/hub/get_room 같은 안전한 조회 요청은 일시적 네트워크 실패 시 1회 자동 재시도
- 브라우저 focus 복귀, online 복귀, visibility 복귀 시 대전 상태 즉시 재동기화
- 대전 상태 version 충돌 시 사용자에게 새로고침을 요구하지 않고 최신 room 상태를 자동 반환
- Realtime 채널 오류 시 LIVE/SYNCING/OFFLINE 상태로 표시하고 전역 오류창을 반복 생성하지 않음
- 내부 Supabase 키/SQL 설치 문구를 일반 플레이어 화면에 노출하지 않도록 상용 메시지로 변환
- Next.js route error/loading/not-found 화면 추가: 일시적 화면 오류가 곧바로 흰 화면으로 끝나지 않도록 복구 UI 제공

## 3. 전투/게임 시스템
- 30장 메인 + 6장 엑스트라 덱 규칙 유지
- 균열 소환 / 공명 융합 / 계승 진화 유지
- Deck Doctor 0~100 진단, 평균 비용/커브/초반 카드/고비용 카드 분석
- 턴 종료 전 남은 행동 경고
- Momentum 전황 표시
- 경기 종료 후 피해/카드 사용/소환/특수소환/회복/드로우 통계
- 희귀도/속성/행동 종류에 따른 전투 VFX 계층 유지
- 흡수는 실제 가한 피해만큼만 회복, 코어/에너지 상한 유지
