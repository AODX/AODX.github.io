# ECLIPSE DUEL v25 — ARCHETYPE SERIES UPGRADE

## 목표
v25는 카드가 개별적으로만 작동하던 구조에서 벗어나, 실제 TCG처럼 **시리즈/아키타입을 중심으로 덱을 연구하고 카드팩을 노려 구매할 수 있는 구조**로 확장한 버전입니다.

## 1. 상점 카드팩 구조 개편
기존 속성별 픽업 팩을 제거하고 아래 구조로 재편했습니다.

### 기본 카드팩 3종
- **일반 카드팩** — 전 속성 랜덤, 희귀 이상 1장 보장
- **희귀 카드팩** — 전 속성 랜덤, 희귀 이상 2장 보장, 희귀/영웅 확률 상승
- **전설 카드팩** — 전 속성 랜덤, 전설 카드 1장 확정

기본 3팩은 태양/달/폭풍/대지/공허/중립 구분 없이 전체 카드 풀에서 나옵니다.

### 시리즈 카드팩 8종
| 시리즈 | 핵심 전술 | 팩 특징 |
|---|---|---|
| 성휘전대 루미나이츠 | 연계 소환 · 전개 강화 | 루미나이츠 카드 2장 이상 보장 |
| 황제기갑 카이저기어 | 보호막 · 에너지 가속 | 카이저기어 카드 2장 이상 보장 |
| 일식공명 이클립시온 | 묘지 회수 · 균열 공명 | 이클립시온 카드 2장 이상 보장 |
| 월영환상 녹턴 미라주 | 회복 · 서치 컨트롤 | 녹턴 미라주 카드 2장 이상 보장 |
| 세계수권속 아르보리아 | 성장 · 광역 강화 | 아르보리아 카드 2장 이상 보장 |
| 천뢰기동 템페스트 드라이브 | 속공 · 에너지 전개 | 템페스트 드라이브 카드 2장 이상 보장 |
| 심연포식 어비스 리퍼 | 묘지 회수 · 코어 압박 | 어비스 리퍼 카드 2장 이상 보장 |
| 원초수호 프라이멀 가디언 | 수호 · 전장 강화 | 프라이멀 가디언 카드 2장 이상 보장 |

시리즈 팩의 일반 슬롯은 75% 확률로 해당 시리즈를 우선 획득하며, 최소 2장은 해당 시리즈 카드로 강제 보장됩니다.

## 2. 실제로 작동하는 SERIES LINK
단순히 카드 이름 앞에 같은 단어를 붙인 것이 아닙니다. 시리즈 핵심 카드에는 실제 엔진 효과가 추가되었습니다.

- **SEARCH SERIES**: 덱에서 같은 시리즈 카드를 손으로 서치
- **RECOVER SERIES**: 묘지에서 같은 시리즈 카드를 회수
- **BUFF SERIES**: 필드의 같은 시리즈 유닛 전체 강화
- **SHIELD SERIES**: 같은 시리즈 유닛 전체에 보호막 부여
- **HEAL PER SERIES**: 필드의 같은 시리즈 수에 비례하여 코어 회복
- **DAMAGE CORE PER SERIES**: 같은 시리즈 수에 비례해 상대 코어 압박
- **GAIN ENERGY IF SERIES**: 일정 수 이상의 같은 시리즈가 있을 때 에너지 회복

유닛 일반/균열 소환, 융합, 진화, 주문 발동, 함정 발동에서 SERIES LINK가 실제 게임 엔진을 통해 처리됩니다.

## 3. 카드 이름 리뉴얼
v8 확장 카드의 임시 생성 느낌이 강했던 이름을 8개 시리즈의 세계관과 역할이 보이도록 정리했습니다.

예시:
- `루미나이츠 글로리 세이버`
- `루미나이츠 어센드 - 피닉스 브레이버`
- `카이저기어 발칸 프레임`
- `카이저기어 어센드 - 아이언 소버린`
- `이클립시온 블랙 레조너`
- `이클립시온 크로스 - 네메시스 키메라`
- `녹턴 미라주 크레센트 댄서`
- `아르보리아 브룸 가디언`
- `템페스트 드라이브 라이트닝 라이더`
- `어비스 리퍼 블랙 리퍼`
- `프라이멀 가디언 루인 비스트`

전체 320장의 표시 이름 중 중복 이름은 0개입니다.

## 4. 덱 빌더 시리즈 지원
- 카드 검색 조건에 **시리즈 필터** 추가
- 추천순에서 SERIES LINK 핵심 카드를 우선 평가
- 시리즈 필터를 선택한 상태에서 자동 구성하면 해당 시리즈를 핵심 엔진으로 우선 구성
- Deck Doctor에서 시리즈 카드 수와 SERIES LINK 엔진 카드 수를 분석
- 시리즈 카드가 부족하면 실제 덱 구성 조언 표시

## 5. 카드 상세 정보
시리즈 카드 상세창에 다음 정보가 분리되어 표시됩니다.
- 시리즈 이름
- 시리즈 핵심 전술
- SERIES LINK 실제 효과
- 기존 카드 효과
- 소환 조건
- 키워드
- LORE

## 6. 글로벌 채팅 30분 보존
글로벌 채팅은 최근 30분 메시지만 표시/보존하는 구조로 변경했습니다.

- 글로벌 채팅을 열 때 30분 초과 메시지 DB 삭제
- 새 글로벌 메시지를 보낼 때도 30분 초과 메시지 DB 삭제 후 삽입
- 화면에서도 60초마다 만료 메시지 제거
- 조회 시 최근 30분 메시지만 최대 60개 로드
- 방 채팅은 기존 동작 유지
- 구형 v5 글로벌 전송 RPC 권한을 회수하여 만료 정책 우회 방지

## 7. 기존 v24 기능 유지
- 신규 스타터 전설 1장 제한
- 결투 중 현재 실제 소환 가능한 전설 카드 표시
- 3D 덱 → 카드 공개 → 손패 진입 드로우 연출
- 상대방 드로우 앞면 비공개

## DB 적용
이미 v24를 사용 중이면 Supabase SQL Editor에서 아래 파일만 한 번 실행합니다.

`sql/05_V25_SERIES_PACKS_CHAT.sql`

v24 스타터 조정을 아직 적용하지 않았다면 먼저:

`sql/04_V24_STARTER_TUNING.sql`

그 다음 v25 SQL을 실행합니다.

기존 보유 카드와 덱은 삭제하지 않습니다. 단, 요청대로 30분이 지난 글로벌 채팅 메시지는 v25 SQL 적용 순간부터 정리됩니다.
