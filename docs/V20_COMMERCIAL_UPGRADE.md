# ECLIPSE DUEL v20 Commercial Quality Pass

이 패치는 v19의 기능을 삭제하거나 게임을 다른 장르로 바꾸는 리메이크가 아니라, 현재 클라이언트를 실제 서비스에 가까운 품질로 끌어올리기 위한 안정화/UX/전투 규칙 패스입니다.

## 이번 패치에서 실제로 변경한 것

### 1. 전투 규칙 정확성
- 흡수(Lifesteal)는 공격력 전체가 아니라 **실제로 체력에 들어간 전투 피해**만큼만 코어를 회복합니다.
- 보호막이 흡수한 피해나 이미 0이 되는 유닛/코어에 들어간 초과 피해를 흡수 회복량으로 계산하지 않습니다.
- 코어 피해는 0 아래로 내려가지 않도록 정규화합니다.
- 에너지 회복 효과가 해당 플레이어의 현재 최대 에너지를 넘지 않도록 수정했습니다.
- 중복된 턴 시간 초과 판정을 제거했습니다.
- 메인 단계에서 배틀 단계로 진입할 때 명확한 BATTLE PHASE 시각 이벤트가 생성됩니다.

### 2. 온라인 대전 신뢰성
- 로그인 직후 최근 `waiting`/`active` 결투방을 서버에서 찾아 자동 복구합니다.
- 브라우저 새로고침이나 짧은 네트워크 단절 이후 진행 중이던 대전으로 돌아갈 수 있습니다.
- 복구 시 서버가 먼저 턴 타임아웃을 정규화하므로 오래 멈춘 클라이언트가 잘못된 턴을 보여줄 가능성을 줄였습니다.
- 결투 행동과 방 행동에 즉시 잠금(ref lock)을 추가해 더블 클릭/빠른 연타로 요청이 중복 전송되는 경쟁 조건을 줄였습니다.

### 3. 카드 상세 UI 전면 보강
- 기존 카드 상세창을 2열 인스펙터 UI로 재구성했습니다.
- 카드 아트, 등급, 속성, 비용, 공격/방어, 소환 방식, 카드 효과, 소환 조건, 키워드, 세부 효과, Lore를 명확한 정보 계층으로 분리했습니다.
- 모바일에서는 단일 열 전체 화면 인스펙터로 전환됩니다.
- ESC 닫기, 배경 클릭 닫기, 최초 포커스, 닫은 뒤 포커스 복원, body scroll lock을 적용했습니다.

### 4. 덱 빌더를 '분석 가능한 도구'로 개선
- 평균 카드 비용을 표시합니다.
- 0-1 / 2 / 3 / 4 / 5 / 6 / 7+ 비용 커브를 그래프로 표시합니다.
- 유닛 / 주문 / 함정 구성 비율을 즉시 확인할 수 있습니다.
- 기존 자동 덱 구성, 보유 수량, 최대 투입 제한, 메인/엑스트라 검증은 유지합니다.

### 5. 카드팩 확률 투명성
- 상점 카드팩에 서버 SQL과 일치하는 **기본 슬롯 희귀도 확률**을 표시합니다.
- 보장 슬롯 수, 최소 보장 등급, 속성 픽업 60%, 승격군 선택 72% 등 해당 팩의 추가 규칙을 함께 표시합니다.
- `RANKED`처럼 실제 시스템이 없는 표현은 제거하고 `QUICK MATCH`로 정확하게 표기했습니다.
- 실질적인 보상 트랙이 구현되지 않은 홈의 `SEASON PASS` 표기는 `SEASON PROGRESS`로 변경했습니다.

### 6. 카드 데이터 편집 품질
- v8 확장 카드에서 반복되던 동일 subtitle/flavor 문구를 카드별 문장으로 교체했습니다.
- 268장의 v8 카드에서 동일 subtitle/flavor 값이 재사용되지 않도록 정리했습니다.
- 중복 키워드(`pierce`, `pierce`)를 자동 정규화했습니다.
- 직접 공격 반격 함정의 텍스트를 실제 엔진 판정인 '공격 유닛 피해'와 일치시켰습니다.
- 수치 밸런스는 플레이테스트 없이 임의로 대규모 변경하지 않았습니다.

### 7. 온보딩 / 접근성
- 상단 GUIDE 버튼으로 게임 안에서 핵심 룰을 즉시 확인할 수 있습니다.
- 승리 조건, 턴 흐름, 에너지, 균열/융합/진화, 수호/속공/흡수/관통, 조작법을 설명합니다.
- 키보드 `focus-visible` 표시를 강화했습니다.
- 운영체제의 `prefers-reduced-motion` 설정을 존중해 모션을 대폭 축소합니다.

## 상용 출시 전에 반드시 남아 있는 작업

이 패치가 '출시 가능한 방향'으로 코드를 끌어올리는 것은 맞지만, 코드 한 번 수정했다고 상용 출시 인증이 끝나는 것은 아닙니다. 실제 판매 전에는 아래가 반드시 필요합니다.

1. Chrome / Edge / Safari / Firefox 및 Android / iOS 실제 기기 QA
2. 2인 온라인 장시간 대전, 재접속, 동시 행동, 턴 타임아웃 반복 부하 테스트
3. 수백~수천 판의 카드 승률/채용률/선공 승률 텔레메트리 기반 밸런스 조정
4. Supabase RLS, RPC 권한, rate-limit, 어뷰징/재화 조작 보안 리뷰
5. 결제 기능을 넣을 경우 환불/미성년자/확률형 상품 표시 등 판매 지역별 법률 및 스토어 정책 검토
6. 사용 중인 카드 아트, 폰트, 효과음, BGM, 아이콘의 상업 이용 라이선스 최종 확인
7. 개인정보처리방침, 이용약관, 계정 삭제/데이터 처리, 고객지원 동선
8. Sentry 등 오류 수집, 서버 로그/알림, 백업/복구, 운영자 도구
9. 랭크를 출시하려면 실제 MMR, 시즌, 매칭 범위, 보상, 이탈/패널티 규칙을 구현한 뒤에만 `RANKED` 명칭 사용
10. 320장 전체 카드의 최종 한글 교정 및 실제 플레이어 대상 설명 이해도 테스트
